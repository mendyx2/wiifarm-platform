# Where things came from

Every file in this repository is written new, **except** the ones listed here.

A file may be brought over from the old system (`mendyx2/wiifarmvest`) only if:

1. `docs/frontend-file-list.md` marks it **Reuse** or **Restyle**;
2. a reviewer has checked it has no wording, layout, images or style names
   from the licensed script, and restyled it where needed;
3. it is added to the table below in the same change that brings it in.

Files marked **Rebuild** are never brought over; they are written again from
the specification.
